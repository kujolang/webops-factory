# Repository work

Read README.md, SECURITY.md and docs/AGENT-SETUP.md before changing the controller. Keep the four repair types explicit and bounded. Never accept commands, arbitrary HTML or new file paths from workers. Use pinned canonical WebOps role contracts, SiteProbe and Lens; keep actual tool receipts distinct from model judgments.

Preserve original source bytes and every run's blocked or successful outcome. Fixture proposals must stay labeled. Changing provider execution or repair operations requires a live example and boundary tests. Run npm run verify before committing. Keep .runtime, authentication and private sites out of Git. Use plain prose and monochrome README badges. Do not add deployment authority without an explicit user request.
